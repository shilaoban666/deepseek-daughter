## 怎么加一段新动画

1. 准备同规格的视频：VP9 带透明通道的 `.webm`，640×360，24 帧/秒。dsh-pet 的素材背景是 1/255 的透明度，播放器会自动扣掉；完全透明的也没问题。
2. 放进 `apps/desktop/assets/pet/whale-girl/clips/`，文件名就是动画名。
3. 在 `pet.json` 里对应的位置加上这个名字（不带 `.webm`），比如发烧就加到 `actions.sick` 里；同时加进 `menu` 的某一组，右键菜单才点得到。
4. 跑 `npm test`。“每一段动画都被用上了”“映射表引用的每段文件都存在”“右键菜单能点到全部动画”三条测试会检查有没有漏。

不用改代码。

## 从 dsh-pet 重新导入

dsh-pet 更新后，可以重新导入：

```bash
cd apps/desktop
npm run pet:import
```

脚本只读 `~/.dsh/profiles/desktop/node_modules/dsh-pet`，会先核对素材条款还在不在、再复制，并更新 `source.json` 和 `clips.sha256`。新版本多出来的动画会在导入时提示“映射表没用到”，按上面第 3 步加进去。
