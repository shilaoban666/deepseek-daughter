## 几个实现上的取舍

- **没有直接用 dsh-memory 做后端。** 按设计文档 §7 的取舍点试过后，选择了自己实现：它和 DSH 的插件形态没有强绑定，也不需要 Python/Rust 依赖，打包更简单。`MemoryBank` 的方法签名（`add / search / recall / decay / mergeSimilar / stats / export / load`）就是预留的替换点，换成 SQLite + sqlite-vec 时只改这一个文件。
- **向量检索暂时用本地特征哈希。** 没有配置嵌入模型时，用字符 n-gram 的哈希向量当兜底，召回评估仍能到 96.7%。接入本地小模型或在线嵌入 API 时，给 `MemoryBank` 传一个 `embedder` 即可。
- **驱力用一个脑子。** 冲动最高且不在冷静期的驱力才会产生想法；吃饭、睡觉这类行为由规则直接执行，省 Token 也更快。
- **免疫先于连接器。** 外部消息入口 `Daughter.receiveExternal` 已经按“陌生人的话只是数据”写好，QQ/微信连接器接进来时直接复用，不用改核心。
- **参数全部在配置里。** 饥饱速度、情绪半衰期、驱力阈值、检索权重、遗忘曲线、备份保留天数都在 `config/default.json`，用户可以在数据目录放 `config.json` 覆盖。
