**目标：** 把桌面端改成两级导航的 8 个板块，并按《稳态与调节》的神经、体液、免疫调节重做生理模型，让每个生理页面都有真实的调节逻辑。

## 全局约束

- 工作目录 `apps/desktop`，测试命令 `npm test`，单文件 `node --test test/<名字>.test.js`。
- 生理模型必须是纯函数，不调用大模型，不读时钟（`now`、`rnd` 由参数传入）。
- 心情、自主活动、说话方式都必须由 `body`、`state` 计算得出，不允许在别处写死。每一条影响都要调用 `addCause`，界面才能回答「为什么」。
- 所有可调参数写进 `config/default.json` 的 `physiology` 段。
- 现有字段 `b.nt`、`b.hpa`、`b.glucose`、`b.hydration`、`b.temp`、`b.immunity`、`b.fever`、`s.satiety` 名字不变，`drives.js`、`immune.js`、现有测试依赖它们。
- 页面 CSP 不改（`connect-src 'none'`），数据一律走 preload。
- 第一屏用人话，数字和参考范围只出现在神经、代谢、免疫三个板块。
- 红黄绿只表示状态，且必须配文字。发光效果只留给 3D 场景。
- 只有当前 Tab 需要时才渲染 3D，WebGL 上下文全程只保留大脑一个、鲸鱼一个。
- 教材只参考概念和数值，不摘抄原文，不把 PDF 入库。
- 生殖系统页只做内分泌层面的数值（性腺轴），不出现任何性内容、身体描绘或互动，这部分数值绝不进提示词。
- 身体数据要注入对话上下文，但她用感受表达，不念数字和医学名词。主人情绪危险时，关怀优先于任何身体状态。
- 这些生理数据只是角色模拟，界面不给用户本人任何健康或医疗建议。
- 她被认真问到是不是 AI 时不否认（现有边界不变）。

## 重点风险（测试归属已写进对应任务）

1. 旧存档没有 `phys` 字段：升级后必须自动补齐，不报错、不丢数据（任务 3）。
2. 应用关了几天再打开，`dtMin` 很大：数值不能发散或越界（任务 3）。
3. 没有 API Key、0 条记忆、刚创建存档：所有页面都有空状态，不报错（任务 2）。
4. 最小窗口 1024×640：代谢板块 6 个 Tab 不换行、不溢出，可横向滚动（任务 1）。
5. 闭环失控：难过 → 想起难过的事 → 更难过，或情绪在两端来回震荡。没有新事件时必须回到基线（任务 8A、8D）。
6. 发烧时回复被限短，却碰上主人情绪危险：关怀内容不能被截断（任务 8C）。
7. 生殖系统数据不能进提示词（任务 8C）。

## 三、因果闭环

这是整个模型的核心。各系统不是并列的仪表，而是一个循环：

```text
事件（吃饭、聊天、被攻击、熬夜）
  → 身体（血糖、激素、免疫、自主神经）
  → 心情与驱力
  → 说话方式和自主活动
  → 写入记忆（带当时的情绪和身体状态）
  → 回忆又改变心情和身体 → 回到下一轮
```

**现状差距：** 现在的提示词只注入 PAD 数值和想做的事，饿了和发烧不会改变她说话的样子（`persona.js:109-116`），回复长度和温度固定（`daughter.js:365`）。记忆虽然存了 `emotion`（`daughter.js:249`），但编码强度和检索都没有用到。活动选择几乎只看时间和精力（`life.js:85-92`）。

**身体状态表（`speech.js` 的 `STATES`）。** 同时满足时按表中顺序取前 2 个：

| id | 触发条件 | 说话的样子 | 自主活动 | 身体反馈 |
|---|---|---|---|---|
| `fever` | `b.fever` 或体温 > 37.3 | 不想说话，一两句带过，可以说不舒服 | 躺着，不主动找人 | 皮质醇升高，精力消耗加快 |
| `exhausted` | `s.energy < 20` | 迷迷糊糊，词不达意 | 提前去睡 | 递质整体偏低 |
| `hungry` | `s.satiety < 30` 或血糖 < 3.9 | 可怜巴巴，没力气，句子短，总念叨吃的 | 优先找吃的 | 交感略升，注意力下降 |
| `thirsty` | `b.hydration < 30` | 嗓子干，顺嘴提想喝水 | 去喝水 | 渗透压升高 |
| `stressed` | 皮质醇 > 55 | 敏感，容易委屈 | 坐立不安 | 免疫缓慢下降，消化变慢 |
| `low` | `pad.P < -0.25` | 话少，语气闷 | 窝着发呆 | 皮质醇驱动增加 |
| `lonely` | `s.social < 25` | 黏人，想多聊一会 | 想找你 | 催产素偏低 |
| `happy` | `pad.P > 0.35` | 话多，语气雀跃，提到心跳快 | 想分享，想出门逛 | 心率上升，多巴胺、血清素活跃 |
